# CoralNPU Study

Notes and experiments on the model-to-simulation pipeline for Google's Coral NPU.

- `coralnpu/` — upstream [google-coral/coralnpu](https://github.com/google-coral/coralnpu) as a git submodule
- `pipeline_layers.svg` — six-layer view of the model → NPU simulation pipeline

Clone with submodules:

```bash
git clone --recurse-submodules https://github.com/LeviDean/CoralNPU-Study.git
```
